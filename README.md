# Subscription Management System

A web-based subscription management application built to track and manage active services, billing cycles, and user subscriptions.

---

## 🚀 Installation & Setup

Follow these steps to get the project running locally on your machine.

### 1. Project Deployment
Move or extract the project folder into your local server's root directory:
* **XAMPP Users:** Move the project folder to `C:/xampp/htdocs/`
* **AMPPS Users:** Move the project folder to `C:/Program Files/Ampps/www/`

### 2. Database Configuration
1. Open your browser and navigate to **phpMyAdmin** (usually `http://localhost/phpmyadmin`).
2. Create a new database named: **`subscription_manager`**
3. Import the provided `.sql` database file into your newly created database.

### 3. Environment Settings
Don't forget to update your database configuration file inside the project:
* Ensure the database name is set to `subscription_manager`.
* Update the database user and password credentials to match your local environment's default settings (e.g., user: `root`, password: your current local password).

---

## 🎉 Usage
Once everything is configured, open your browser and head to `http://localhost/your-project-folder-name`. 

Enjoy using the application!
